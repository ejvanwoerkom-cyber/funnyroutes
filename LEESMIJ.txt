FUNNYROUTES ANALYTICS DASHBOARD

Upload naar GitHub:
1. admin-analytics.html -> hoofdmap
2. api/admin-analytics.js -> map api

Daarna in Vercel:
Project FunnyRoutes -> Settings -> Environment Variables

Nieuwe variabele:
Name: ANALYTICS_ADMIN_KEY
Value: kies zelf een lange geheime sleutel/wachtwoord
Environment: Production

Daarna Redeploy uitvoeren.

Dashboard:
https://funnyroutes.com/admin-analytics.html

De geheime sleutel wordt niet in de HTML opgeslagen.
De browser bewaart hem alleen tijdelijk in sessionStorage totdat het tabblad wordt gesloten of je uitlogt.
